# 캐주얼 조준·시점·전장

2026-10-27 · editor-tooling-codex / gameplay-programmer-codex

사용자의 캐주얼 개선 승인에 따라 쉬운 조준, 안정적인 카메라, 밝은 전장 색감을 우선 적용한다. 지형 파괴·엄폐·피해·이동·승리 조건은 유지한다.

- 바람을 반영한 조준선과 착탄 예상 원. 클러스터의 원은 첫 가시 착탄 예고이며 모든 자탄의 피해 범위가 아니다.
- 일반탄은 넓은 구도로 관찰하고 특수탄은 기존 추적 연출을 사용한다. 카메라 복귀 후 AI 준비 시간은 유지한다.
- 내 탱크 뒤에서 상대를 보는 조준 시점, 화면 왼쪽의 내 탱크 보기/상대 보기 버튼. 우클릭 회전·휠 줌을 유지한다.
- 청록/주황 탱크 식별색, 밝은 낮 조명, 초지/도로/암반의 색 대비. 물리적 경계와 외곽 안개는 유지한다.

Unity의 `Fortress > Upgrade Casual Presentation`은 두 대전 씬과 관련 설정·재질을 갱신한다. 기존 UI를 다시 생성한 경우 마지막에 실행해야 시점 버튼이 복원된다. 기존 수동 카메라와 추적 동작은 설정의 `casualPresentation`을 끄면 사용할 수 있다.

직격 알림·피해 숫자·튜토리얼·경기 시간 밸런싱은 이번 작업 범위에 포함하지 않는다.

## 검증

관련 PlayMode 32/32 통과(63.518초): 캐주얼4·조준3·수동카메라4·추적7·AI8·메뉴6. 기존 수동 카메라 검사는 설정 복제본에서 기존 모드를 검사하고, 신규 검사는 저장된 캐주얼 프리셋을 검사한다. `Validation/casual-playmode.json` 참조.

Full HD 조준/일반탄 전장 관찰 화면을 확인했다(`Validation/casual-aim.png`, `Validation/casual-wide-shot.png`). 일반탄 화면에서 포탄 viewport (0.48, 0.56) 확인. 최종 재질은 사진 노이즈 대신 작은 자체 생성 색상 텍스처, 무광 지면을 사용한다. 지형 물리 높이는 변경하지 않았다. 별도 실행파일 빌드·프레임 성능은 이번 검증에 포함하지 않았다.
